# 执行模型修复与真实Tushare验收

日期：2026-10-28；修复基线a8103e2。具体版本以包含本文档的Git提交为准。

## 三项问题与修复

F1曾在两张BUY100限价单、150股共享预算时出现100+50+50股原生回调，随后预算断言中断。根因是NT1.231.0的L1撮合在模拟盘口耗尽后给可成交限价单追加一跳成交。这与回调后扣减的自定义预算发生冲突，不是异常行情输入。

现在采用`bar-synthetic-l2-v1`：Bar派生的合成深度送入官方NT原生L2撮合，避免L1特有的耗尽盘口追加成交。每次模拟量取共享剩余预算、订单剩余量与现金可支付量的上限，成交回调仍保留超量断言。没有修改NT安装包，没有直接生成成交或事后删改账本。150股预算下正确成交100+50，剩余DAY委托日终取消。

F2以前会使买限价9.90按Bar低点9.80成交、卖限价10.55按Bar高点10.60成交。现在开盘可成交挂单仍按开盘报价给予合理价格改善；盘中触价一律按委托限价成交，不按Bar极值给予优价。价格、数量及模型名称写入结果。

F3以前在停牌日无Bar时保留pending意图到复牌，有零量Bar时则拒绝。现在每个交易日开始时，按日规则对进入SUSPENDED/DAY_BLOCKED的未提交意图统一拒绝。拒绝发生在首个停牌日，不需触发占位Bar回调。原生DAY订单日终撤单规则不变。这不等于所有策略在不同占位历史下必然产生相同信号；研究数据表示仍需统一。

## 明确的研究假设

- 输入仍为未复权OHLCV，不需要真实L2数据。合成深度不是历史盘口，不应称为高保真L2重建。
- 每根Bar按O-H-L-C固定顺序提供合成深度；高、低、收三个点的技术时间放在Bar结束前3/2/1纳秒，仅表达内部顺序，不是这些价格实际发生时刻。原始Bar结束后才调用策略信号。
- 开盘报价在Bar起始处，意图最早在下一Bar执行。日Bar成交量仍是整Bar事后预算，不代表开盘瞬间流动性；上一已知Bar参与率申报限制保留。
- 所有方向、订单及合成点共享同一Bar预算，快照更新不补回已消耗预算。
- 非开盘触价按限价是一项保守价格规则，不证明实际排队可成交。触碰即具备撮合资格及固定O-H-L-C顺序仍可能带来成交概率/路径偏差。
- 无真实队列、竞价、逐笔冲击、盘中停牌重建，不能据此声称实盘成交可复现。

## 真实数据细节

本轮复用已冻结的官方响应，并新查询Tushare停复牌、行情、涨跌停和公司行为数据；从未读取或提交交易账户。新样本为002128.SZ，2025-04-28至2025-06-30，停牌日与复牌日均由供应商记录确定，实际行情缺口与停牌状态交叉核验。

1. R12：600000.SH，2025-01-03真实成交量50693944股，按参与率约0.0000029609形成150股预算；两笔100股限价10.23的买单实际成交100+50股，原始价格和量未改动。
2. R13：600000.SH，2025-01-06开盘10.13、最低9.81，前收10.06作为买入限价，实际按10.06成交，没有使用9.81。
3. R14：600000.SH，2025-01-07开盘10.11、最高10.30，卖出限价10.15，实际按10.15成交，没有使用10.30。
4. R15：002128.SZ，停牌前信号在首个停牌日以SUSPENDED拒绝，之后即使复牌也没有成交；只使用真实开市日Bar，停牌日不造行情。
5. R16：同一原始快照增加明确标记的结转价零量占位记录，得到相同拒绝结果。占位是归一化对照，不是新采集到的行情，不用于成交。

每个场景先给定预期交易，再核对原生成交、独立费用、现金、T+1批次、公司行为和逐日权益。现金到分、股数精确、权益容差1e-6元；不以策略赚钱作为验收标准。新限价模型使挂单价格按声明发生变化，不能强求旧版极值成交收益不变；原11个主要常规路径的经济结果保持一致。

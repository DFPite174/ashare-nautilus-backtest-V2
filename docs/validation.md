# 常规 A 股回测修复与验收

日期：2026-10-27。基线：`ef26e8b268fe5dd6fb638e65c4e0ce3e301ae9d6`。

目标是沪深普通股票、现金多头、多日持有、日线和分钟线的可复用资金回测。使用官方 NautilusTrader Python 包驱动其原生回测、撮合、账户和持仓；没有改写撮合引擎，没有实盘接入。不能将此实现称为纯 Rust 回测主程序。

## 对账能证明什么

原生账户资金确实由订单成交和公司行为改变；不是把参考账本余额抄入结果。参考持仓由成交逐笔计算，原生、网关和账本逐日对照，费用另以预期费用函数检查。派息原生与账本分别计算权益，能够发现半分钱舍入差异。

但双方共用原始行情和估值输入，因此对账一致不能证明价格真实、公司行为数据无漏项、公告时点正确或 Bar 成交路径能实盘实现。停牌除权虚增净值正是通过经济守恒反例而非三方相等才被识别。

1. 保持交易前校验→原生订单→成交回调→参考记账→日终对账链路，禁止直接伪造成交或只改参考账本掩盖漂移。
2. 使用 README 数据契约准备完整未复权行情、历史证券日规则、权威日历及公司行为；禁止用前/后复权价格加上再次送转分红。
3. 缺失 OPEN 行情/规则、非法价格/单位/时间戳要失败，不能当成停牌、补齐或静默换数据源。
4. 涉及现金、持仓、公司行为、撮合或日历的新改动，先补最小失败反例；保留每轮输入/红绿日志/JSON，不只保存最终收益。
5. 下一阶段优先在本地真实数据上做一买一卖、分红再投、送转上市、停牌跨日和多证券共享资金的小样本核验，然后再跑常规策略。没有本地真实数据证据前，不宣称收益有效或全市场适配完整。
6. 不添加实盘/券商连接；不将现有 Windows/Python3.12 NT1.231.0 的拆股 ABI 称为跨平台通用。

## 保留边界

Bar 模型不复原集合竞价、队列、逐笔盘口、真实滑点与冲击。价格笼子以前开盘近似报价检查；涨跌停采取保守侧向阻断；停牌期间按结转参考估值，无自动长期停牌减值政策。分钟内部缺口须预处理核验。

公共运行器尚未涵盖融资融券、个人差别化股息税、配股、要约收购、退市结算、高频、美股/港股及其他资产。已有 market_rules 的独立函数存在不等于这些流程已经接入公共运行器。公司行为税前口径及现金替代假设必须写进研究元数据。
